# Fresh Fruit — Атырау

Одностраничный сайт-визитка (link-in-bio) для магазина **Fresh Fruit**, Атырау.
Статичный сайт без сборки: один `index.html` + картинки.

## Возможности

- Два языка — русский и қазақша (переключатель вверху, выбор запоминается)
- Светлая и тёмная тема (по системной, можно переключить вручную)
- Живые часы Атырау (UTC+5)
- Анимации: плавный градиентный фон, появление блоков при скролле, блик на кнопке звонка, ripple при нажатии
- На компьютере кнопка «Позвонить» копирует номер в буфер обмена
- Кнопка «Поделиться» — системное меню share, иначе копирует ссылку
- PWA: сайт можно добавить на главный экран телефона
- Картинка-превью для WhatsApp / Telegram (`assets/og.png`)
- Доступность: контраст выше WCAG AA, поддержка `prefers-reduced-motion`, навигация с клавиатуры

## Как поменять контент

Всё содержимое — в `index.html`.

- **Телефон**: найдите `+77784443298` (в `href="tel:"`, в `PHONE` в скрипте и в JSON-LD) и `+7 778 444 3298` (видимый текст).
- **Ссылки**: обычные `<a href="...">` в разметке.
- **Тексты на двух языках**: атрибуты `data-ru="..."` и `data-kk="..."` на одном элементе.
- **Цвета**: CSS-переменные в начале `<style>` (`--lime`, `--orange`, `--green`).

Логотип и иконки лежат в `assets/`. При замене сохраните имена файлов.

## Локальный запуск

Любой статический сервер из корня проекта, например:

```bash
npx serve .
```

## Деплой

Продакшн собирается автоматически из ветки `main` (Vercel).
Настройки заголовков и кеша — в `vercel.json`.
